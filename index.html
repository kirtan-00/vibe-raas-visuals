For the VJ

  1. On the LED laptop, open the SHOW window in Chrome and drag it onto the LED. Its start screen shows a 4-letter room code and a QR code.
  2. Scan that QR with your phone (or type the code at control.html). Or open CONTROL on the laptop itself: same Chrome works even offline.
  3. Click the show to start, press Allow for the microphone, then press F for fullscreen.
  4. More phones can join with the same code (VJ and organiser together). Every phone stays in sync and shows how many controllers are connected. Last tap wins.
  5. Big stage LED: open Stage 3000x720 (or pick Stage screen on the show's start screen), drag that window onto the stage LED output, click it, press F. Side LEDs use Side screen. All windows join the same room.
  6. On the phone, the Screens bar picks who a tap goes to: All, Stage or Sides. Tap tempo always goes to every screen.
  7. Pick the centre logo from the phone: Vibe Raas, Vibe Tribe, Sach Raatri, Clapper, Fourside or Off. It stays put when you switch visuals.

No internet at the venue?

  1. While still online, open the SHOW window once and wait for Offline ready under the start button.
  2. Keep that tab open (or reopen the same address later in the same Chrome): every visual, colour and logo works with no internet. Only phone control needs internet.
