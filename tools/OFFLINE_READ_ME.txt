VIBE RAAS VISUALS: OFFLINE COPY
No internet and no install needed. Everything is inside one file.

START
1. Unzip this folder anywhere (Desktop is fine).
2. Open "Vibe Raas Visuals.html" in Google Chrome.
   (Right click, Open With, Google Chrome. Safari is not supported.)
3. Drag the window onto the LED screen.
4. Click "Side screen" (side LEDs) or "Stage screen" (the 3000x720 stage LED).
5. Chrome asks for the microphone: press Allow. The visuals follow the music.
6. Press F for fullscreen.

F  fullscreen on or off
Up / Down arrows  more or less intensity
T or Space  tap the tempo if the mic is not picking up the beat

GOOD TO KNOW
Keys work even if you clicked on the visual.
Phone control does not work in this copy. It needs internet.
If Chrome asks for the mic every time, that is normal for a file on disk. Press Allow.
Mixer line out into the laptop works best. The laptop mic also works.
No mic at all? The visuals still run on an automatic beat. Tap T to set the speed.
